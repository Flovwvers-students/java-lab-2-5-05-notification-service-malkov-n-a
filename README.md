# Java 2.05 — Сервис рассылки уведомлений

Проект реализует учебную рассылку уведомлений по каналам Email, SMS и Push с учётом разрешений пользователя. Если канал отключён, отправка пропускается. Если необходимого контакта нет, ошибка обрабатывается без остановки рассылки.

## Требования

- JDK 21
- Терминал Linux (или встроенный терминал IntelliJ IDEA)
- Дополнительные библиотеки не требуются

## Сборка

Все команды выполняются из корня репозитория (папки, содержащей `src`).

```bash
mkdir -p out
javac -encoding UTF-8 -d out src/*.java
```

## Демонстрация

```bash
java -cp out Main
```

Демонстрация выполняет два сценария:

1. Перенос пары в аудиторию 304 по Email и SMS: Email Анне доставляется, SMS Анне выдаёт ошибку из-за отсутствия телефона, Email Борису пропускается, SMS Борису доставляется.
2. Напоминание о сдаче лабораторной № 5 до 13 ноября по Email, SMS и Push: Push Анне пропускается, Push Борису доставляется.

### Результат демонстрации

```text
=== Перенос пары ===
Email -> Анна (anna@example.com): Пара перенесена в аудиторию 304
Ошибка доставки: Анна, sms: Отсутствует телефон
Пропущено: Борис, email
SMS -> Борис (+79991234567): Пара перенесена в аудиторию 304

=== Напоминание о дедлайне ===
Email -> Анна (anna@example.com): Напоминание о сдаче лабораторной № 5 до 13 ноября
Ошибка доставки: Анна, sms: Отсутствует телефон
Пропущено: Анна, push
Пропущено: Борис, email
SMS -> Борис (+79991234567): Напоминание о сдаче лабораторной № 5 до 13 ноября
Push -> Борис (ID 2): Напоминание о сдаче лабораторной № 5 до 13 ноября
```

## Тесты

```bash
java -cp out NotificationServiceTest
```

Ожидаемый результат:

```text
Все проверки пройдены.
```

`NotificationServiceTest` проверяет порядок доставки и пропусков в обоих сценариях, однократное формирование текста уведомления и исключения при отсутствии обязательных контактов.
